# 🔐 DDOS-WiFi

**Тулкит для аудита собственной Wi-Fi сети: открытые порты · устройства в сети · «кто подключён к моему Wi-Fi» · отчёт по безопасности · защита от DDoS**

*Python 3.8+, без зависимостей, Windows / macOS / Linux*

</div>

---

> [!WARNING]
> ### ⚠️ Только для легального использования
> Инструмент создан **для проверки безопасности СВОЕЙ сети** — дома или в организации,
> где у вас есть разрешение на аудит. Сканировать чужие сети и устройства без согласия
> владельца — незаконно. Здесь **нет и не будет** функций для DDoS-атак, взлома или
> перехвата трафика: только проверка и защита. Запуск DDoS-атак — уголовное
> преступление (в РФ — ст. 274.1 и 272 УК РФ).

## ✨ Возможности

| Команда | Что делает |
|---|---|
| `wifi` | 📶 Информация о текущем Wi-Fi подключении: SSID, BSSID, канал, сигнал, тип защиты (WPA2/WPA3/WEP), частота |
| `devices` | 📡 Находит все устройства в локальной сети: IP, MAC, производитель, имя хоста (ARP + ping + TCP) |
| `clients` | 👥 **«Кто подключён к моему Wi-Fi?»** — список клиентов с ролями (роутер / Wi-Fi клиент / это устройство) |
| `ports` | 🎯 Сканер открытых TCP-портов с определением служб и баннеров + пометки опасных портов |
| `report` | 🛡️ Полный отчёт по безопасности: риски, оценка 0–100, персональные рекомендации, сохранение в файл |
| `ddos-info` | 📚 Что такое DDoS, как распознать атаку на роутер и как защититься (только про защиту!) |
| `network` | 🌐 Параметры сети: IP, подсеть, шлюз, Wi-Fi интерфейс |
| `menu` | 🖥️ Интерактивное меню — всё то же самое по цифрам |

**Ключевые особенности:**
- ✅ **Ноль зависимостей** — работает на чистой стандартной библиотеке Python
- ✅ Кроссплатформенность: Windows (`netsh`), macOS (`airport`/`ipconfig`), Linux (`nmcli`/`iw`/`iwconfig`)
- ✅ Сканер портов не требует прав администратора (TCP connect-скан)
- ✅ Встроенная база производителей по MAC (Apple, Samsung, Xiaomi, TP-Link, MikroTik, Raspberry Pi, IoT и др.)
- ✅ JSON-режим у всех команд — удобно для автоматизации
- ✅ Перед сканированием просит подтвердить право на аудит

## 📖 Использование

```text
  1. Информация о Wi-Fi подключении
  2. Найти устройства в локальной сети
  3. Кто подключён к моему Wi-Fi / сети
  4. Сканировать открытые порты
  5. Отчёт по безопасности сети
  6. Что такое DDoS и как защититься
  7. Параметры локальной сети
  0. Выход
```

### 🎯 Сканер открытых портов

```bash
python -m wifi_audit ports 192.168.1.1 -p top          # типовые порты роутера
python -m wifi_audit ports 192.168.1.5 -p 22,80,443    # конкретные порты
python -m wifi_audit ports 192.168.1.5 -p 1-1024       # диапазон
```

```text
+------+-------------+-----------+--------------------------------------------------+
| Порт | Служба      | Состояние | Баннер                                           |
+------+-------------+-----------+--------------------------------------------------+
| 22   | SSH         | ОТКРЫТ    | SSH-2.0-OpenSSH_9.2p1                            |
| 80   | HTTP        | закрыт    | —                                                |
| 8000 | HTTP        | ОТКРЫТ    | HTTP/1.0 200 OK  Server: SimpleHTTP/0.6          |
+------+-------------+-----------+--------------------------------------------------+

Открыто: 2 из 5

[!] Замечания по безопасности:
  ⚠ порт 22 (SSH): SSH — нормально, но включите вход по ключам
```

### 📡 Устройства в сети и «кто подключён к моему Wi-Fi»

```bash
python -m wifi_audit devices     # все устройства подсети
python -m wifi_audit clients     # кто сейчас подключён
```

```text
+--------------+-------------------+---------------+-----------+----------------+
| IP-адрес     | MAC               | Производитель | Имя хоста | Роль           |
+--------------+-------------------+---------------+-----------+----------------+
| 192.168.1.1  | a4:2b:b0:xx:xx:xx | TP-Link       | —         | роутер (шлюз)  |
| 192.168.1.10 | dc:a6:32:xx:xx:xx | Raspberry Pi  | —         | Wi-Fi клиент   |
| 192.168.1.15 | —                 | —             | —         | это устройство |
+--------------+-------------------+---------------+-----------+----------------+
```

Увидели незнакомый MAC? Смените пароль Wi-Fi (WPA2/WPA3) и включите в роутере
фильтрацию MAC-адресов как дополнительную меру.

### 🛡️ Отчёт по безопасности

```bash
python -m wifi_audit report
```

Что проверяется:
- 🔐 шифрование Wi-Fi: **WEP / Open — критично**, WPA(TKIP) — устарело, WPA2/WPA3 — норма;
- 🚪 открытые порты роутера (Telnet, FTP, SMB, RDP, UPnP, Redis и др.) с объяснением рисков;
- 🖥️ количество устройств в сети;
- 📊 итоговая оценка **0–100** и список рекомендаций;
- 💾 сохранение в `reports/report_*.txt` + `report_*.json`.

### 📚 Про DDoS — только защита

```bash
python -m wifi_audit ddos-info
```

Раздел объясняет простыми словами: что такое DDoS, типы атак, признаки атаки на ваш
роутер, пошаговый план действий при атаке и чек-лист профилактики.

## ❓ FAQ

**Не видит мои Wi-Fi данные?**
- Windows: проверьте `netsh wlan show interfaces` — Wi-Fi должен быть подключён.
- macOS 14+: системе нужно разрешение на доступ к имени SSID (Настройки → Конфиденциальность).
- Linux: нужны `nmcli`, `iw` или `iwconfig` (NetworkManager/wireless-tools).

**Почему не видны некоторые устройства?**
Устройства с файрволом могут не отвечать на ping/TCP — их видно только в ARP после
активности. Это ограничение всех пассивных методов, так работают и роутеры.

**Чем это отличается от nmap/aircrack-ng?**
Это «маленький дружелюбный аудит»: без зависимостей, с русским интерфейсом,
оценкой безопасности и объяснениями. Полноценные инструменты (nmap, Wireshark,
aircrack-ng) всё ещё нужны для глубокого тестирования.

**Здесь есть DDoS-атаки?**
Нет и не будет. Инструмент показывает только состояние СВОЕЙ сети и учит защищаться.

## 🧱 Структура проекта

```text

├── __main__.py    # точка входа: python -m wifi_audit

└── utils.py       # цвета, таблицы, база OUI-производителей
```
